# WareTrack · 智慧物流数字孪生

参考物流园区视觉的中文三维数字孪生交互原型。使用 Three.js 与原生 HTML / CSS / JavaScript，无构建依赖；Three.js、OrbitControls 及许可证均随项目提供。

## 本地运行

在项目目录执行 `python3 -m http.server 8080 --directory dist`，访问 http://localhost:8080。

也可以执行 `npm start`。项目无需安装 npm 依赖；本地启动需要 Python 3。

## 验证

执行 `npm run check`，验证真实 Three.js 几何构建、车辆选择、三车循环、暂停 / 恢复、门未开到位时等待、独立月台感应、驶离延迟关门、门模型同步、搜索与视角控制。此检查不验证 GPU 渲染或浏览器视觉效果。

## 功能

- 实时渲染的三维园区、仓库、月台、货车、叉车、绿化与入口。
- 拖动旋转、滚轮缩放、俯视、重置、全屏及图层开关。
- 点击模型、标签或车辆列表选择车辆；定位车辆并查看运单。
- 三辆车自动循环作业，支持暂停、倍速与重置；车辆接近自动开仓库门，门开到位后倒车停靠，装卸结束驶离后延迟关门。
- 仓库卷帘门真实升降动画、状态指示灯、门状态标签与车辆 / 月台面板同步。
- 资产搜索、车辆 / 月台 / 叉车列表、园区通知及运营分析。
- 响应式桌面与移动布局。

所有业务数据为模拟数据；本原型未接入真实 WMS、TMS、GPS 或物联网数据。字体有系统字体回退，3D 场景与业务交互不依赖外部 CDN。
