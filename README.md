# WareTrack · 智慧物流数字孪生

参考物流园区视觉的中文三维数字孪生交互原型。使用 Three.js 与原生 HTML / CSS / JavaScript，无构建依赖；Three.js、OrbitControls 及许可证均随项目提供。

## 本地运行

在项目目录执行 `python3 -m http.server 8080 --directory dist`，访问 http://localhost:8080。

也可以执行 `npm start`。项目无需安装 npm 依赖；本地启动需要 Python 3。

## 验证

执行 `npm run check`，验证独立车辆身份、左侧进右侧出、连续运动、车体避碰、满载放行、门联锁、叉车叉货 / 入库 / 空车返回、单车入库通行、库存守恒、动态模型清理、暂停与重置。此检查不验证 GPU 渲染或浏览器视觉效果。

## 功能

- 浅色全视图数字孪生：3D 园区铺满主视图，六项 KPI、库存趋势、车辆流转环图、装载率、月台利用率和吞吐图表集中在右侧可滚动浮层；手机端支持展开 / 收起图表。
- 图表读取实际模拟数据，保留最近 60 秒库存观测、5 秒吞吐分组及本次运行的月台占用时间；暂停冻结数据，重置清空历史。
- 常驻卡片只展示图形与关键数字，完整运单、车辆和设备详情通过点击查看。

- 实时渲染的三维园区、仓库、月台、货车、叉车、绿化与出入口。
- 车辆从左侧入口进入，沿入场车道行驶、转向倒车停靠；仓库门开到位后逐托盘装货，满载后沿出场车道从右侧出口驶离。
- 新入场车辆使用独立车牌、司机与运单；已完成车辆移出场景，新车辆按月台空闲情况调度，不将同一辆车移回起点。
- 车辆会转向、车轮随路程滚动；入场与出场车道分离，倒车入位避让出场车辆，车体之间保持间距。
- 三辆叉车从暂存区叉起真实托盘，举升后载货驶入 WH-02 仓库，放货后空车退出并沿返回通道继续取货；入库门只允许一辆叉车通行。
- 仓库卷帘门、园区道闸、门状态指示灯与详情面板联动。
- 叉车完成入库增加库存，车辆逐托盘装货扣减库存；缺货时等待，车辆只有装满 8 托盘才可离场。
- 车辆、叉车、月台列表和运单进度、库存、园区车辆数、离场总数、入库总数动态更新。
- 支持旋转、缩放、俯视、定位、全屏、图层、暂停、倍速与任务重置。
- 响应式桌面与移动布局。

所有业务数据为模拟数据；本原型未接入真实 WMS、TMS、GPS 或物联网数据。字体有系统字体回退，3D 场景与业务交互不依赖外部 CDN。
